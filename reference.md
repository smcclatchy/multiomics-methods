## Glossary

feature
: a specific characteristic or attribute of biological data, such as a gene, 
protein, or nucleotide sequence, that can be analyzed or used for 
interpretation.

metadata
: data about the data. Metadata describes the data and makes it easier to 
locate, manage, or use. 

principal component
: a new variable created as a linear combination of the original variables in a 
dataset, which captures the most variance. 

Principal Component Analysis (PCA)
: a technique for dimensionality reduction that helps in identifying patterns in 
complex biological data.

singular value decomposition
: a mathematical technique in linear algebra that factors a real or complex 
matrix into three components: a rotation, a scaling, and another rotation. It is 
expressed as $M = U\SigmaV$, where $U$ and $V$ are orthogonal matrices and 
$\Sigma$ is a diagonal matrix containing the singular values, which indicate the 
strength of each pattern in the data.
